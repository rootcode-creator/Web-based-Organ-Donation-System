# 🫁 Web-based Organ Donation System

A web application for managing organ donation processes, built and maintained by [rootcode-creator](https://github.com/rootcode-creator).

---

## 🌟 Overview

This project is designed to facilitate organ donation management, including donor registration, recipient matching, and administrative tasks, all through an intuitive web interface.

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** PHP
- **Database:** MySQL

---

## 🧩 Features

- **Donor Registration:** Secure sign-up for potential organ donors
- **Recipient Management:** Track and match recipients with available donors
- **Admin Dashboard:** Manage users, donations, and system data
- **Status Tracking:** Monitor the progress of donations and transplants
- **Notification System:** Alerts for matches and updates

---

## 🚀 Getting Started

1. **Clone the repository:**
    ```bash
    git clone https://github.com/rootcode-creator/Web-based-Organ-Donation-System.git
    cd Web-based-Organ-Donation-System
    ```
2. **Set up the database:**
    - Import the SQL file (if provided) into your MySQL server.
    - Update database credentials in the PHP config file.

3. **Configure environment variables:**
    - Edit settings such as database credentials in the configuration files.

4. **Run the application:**
    - Host the project in a PHP-supported web server (e.g., XAMPP, WAMP, LAMP).
    - Access the web interface from your browser.
